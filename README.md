# Tarank: Numerology and Number-Based Astrology

A single-page website that calculates a person's numerology chart from a name and birth date, links it to astrology, and explains the numbers 1 to 9. It is plain HTML, CSS and JavaScript in one file, with no build step and no dependencies.

**Live demo:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/ (replace after enabling GitHub Pages)

## What it does

- **Core numbers:** psychic (birth day), destiny (full birth date) and name number, plus Life Path, Expression, Soul Urge, Personality, Maturity and Personal Year, Month and Day.
- **Lo Shu grid:** shows which digits appear in the birth date and which are missing, inside a zodiac ring that highlights the sun sign.
- **Astrology link:** maps numbers to planets and compares them with the sun sign and its ruling planet.
- **Life stages:** four pinnacles with ages and challenges, and the nine-year cycle.
- **Year numbers:** this year and next, using Johari's weekday method.
- **Couples tool:** compatibility for two people (love, growth, married life, peace, tension, happy living), using planet friendships, sun-sign elements and name numbers.
- **Name check:** up to four spelling suggestions that move a name total to a chosen number.
- **Extras:** light and dark theme toggle, printable report, responsive layout.

## Run it locally

Download `index.html` and open it in any modern browser. Nothing else is needed. Fonts load from Google Fonts when online and fall back to system fonts when offline.

## How it is built

- Vanilla JavaScript for all calculations and rendering
- CSS custom properties for theming, with a light and a dark theme
- Inline SVG for the number wheel, zodiac ring and side artwork
- Responsive grid layout, keyboard-focus styles and reduced-motion support
